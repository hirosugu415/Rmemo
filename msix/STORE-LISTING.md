## 説明

```
思いついた瞬間に、Ctrl + N。

Rmemo は、どの画面からでもホットキーひとつで呼び出せるメモアプリです。ブラウザで調べものをしているときも、資料を作っているときも、今の作業の上に小さな入力窓が開きます。書いたそばから見出しやリストが整い、閉じればすぐ元の作業に戻れます。

■ すぐ書ける
・Ctrl + N で、どこからでも入力窓を開けます（キーは変更できます）
・書いている途中も自動で保存。Ctrl + Enter で保存して閉じます
・タスクトレイに常駐し、Windows の起動と同時に立ち上がります

■ 書いたそばから整う
・見出し、箇条書き、チェックボックス、引用、コードブロックを、Markdown で打ったその場できれいに表示します
・日本語入力のまま「＃＃　」と打っても見出しになります
・スクリーンショットは Ctrl + V で貼るだけ。大きさもドラッグで変えられます

■ 残すメモと、使い捨てのメモ
・あとで読み返すメモは「Keep」、とりあえず書くメモは「Scratch」。Ctrl + L で切り替えます
・古くなった Scratch には印が付き、整理画面で 1 件ずつ「残す / 捨てる」を決められます

■ 探す・つなぐ
・全文検索とタグ（#タグ）で、すぐに見つかります
・[[メモ名]] で別のメモにリンク。リンクされた側には参照元が表示されます
・よく使うメモはピン留めして一番上に

■ エディタとしても本格的
・複数カーソル、行の移動・複製、見出しの折りたたみ、目次、検索・置換
・VS Code と同じキー操作（Ctrl + D、Alt + ↑↓ など）に対応

■ メモは、ただのテキストファイル
・メモは「ドキュメント\Rmemo」に、1 メモ = 1 つの .md ファイルとして保存されます
・アプリがなくてもメモ帳や VS Code で開けます。Rmemo をやめても、メモはそのまま残ります
・保存フォルダを Google ドライブなどに置けば、複数の PC で同じメモを使えます
・アカウント登録は不要。メモを外部に送信することはありません

すべての機能と操作方法は、アプリの中で F1 を押すと入力例つきで確認できます。
```

## 申請オプション：runFullTrust の利用理由

制限付き機能 `runFullTrust` の理由を聞かれたら、次の文を入れる。

```
Rmemo はデスクトップアプリ（Win32）として動作し、次の機能のために runFullTrust が必要です。
・どのアプリを使っている最中でも入力窓を開くためのグローバルホットキーの登録
・タスクトレイへの常駐
・利用者が選んだフォルダ（既定ではドキュメント\Rmemo）へのメモファイルの読み書きと、その変更の監視
アプリはメモを外部に送信しません。
```

## 年齢区分（IARC のアンケート）

答え方の目安。どれも「いいえ」になる。

- 暴力・性的な表現・ギャンブルなどの内容 → なし
- ユーザー同士のやり取り（チャット、投稿の共有など） → なし（メモは本人の PC の中だけ）
- 位置情報の共有 → なし
- アプリ内購入・広告 → なし

結果は「3 歳以上」相当になるはず。

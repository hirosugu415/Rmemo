Rmemo

プライバシーポリシー

最終更新日: 2026年10月20日

このページでは、メモアプリ「Rmemo」（Windows 用アプリ、およびスマホ用の閲覧アプリ）が 扱う情報について説明します。

収集する情報

Rmemo は、利用者の個人情報やメモの内容を収集しません。開発者のサーバーにデータを送信することはなく、 利用状況の解析（アクセス解析やクラッシュレポートなど）も行いません。広告も表示しません。

Windows 用アプリ

  • メモは、利用者の PC 上のフォルダ（既定では Documents\Rmemo）にテキストファイルとして保存されます。
  • 設定は、利用者の PC 上の %APPDATA%\Rmemo に保存されます。
  • 新しいバージョンがあるかを確認するため、GitHub（github.com）に接続します。 このとき送信されるのは、通常の Web アクセスと同じ情報（IP アドレスなど）だけで、メモの内容は送信されません。
  • 同じ PC 上の他のアプリがメモを読み書きするためのローカル API（127.0.0.1）を備えています。 この API は同じ PC の中からしか接続できず、トークンで保護されています。設定で無効にできます。
  • メモの保存フォルダを Google ドライブなどのクラウドストレージに置いた場合、同期はそのサービスのアプリが行います。 その場合のデータの扱いは、各サービスのプライバシーポリシーに従います。

スマホ用の閲覧アプリ

  • 閲覧アプリは、利用者が Google アカウントでログインしたときだけ、利用者の Google ドライブにあるメモを読み取ります。 要求する権限は、ドライブのファイルの読み取り（drive.readonly）だけです。ファイルの作成・変更・削除は行いません。
  • 読み取ったメモは、利用者のブラウザの中だけで表示され、オフラインでも読めるようにブラウザ内に保存されます。 開発者を含む第三者には送信されません。
  • ログイン情報（一時的なアクセストークン）は、利用者のブラウザ内にだけ保存され、約 1 時間で無効になります。
  • Google API から受け取った情報の利用と他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に従います。
  • ログアウトすると、アクセストークンは取り消されます。Google アカウントの サードパーティのアクセス設定から、いつでもアクセスを取り消すこともできます。
